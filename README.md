# FileMaker Articles and Demo Files

This repository collects FileMaker articles with the demo files, screenshots, source exports, code libraries, and pasteable snippets used to build and document them.

## Series

- [Beyond the Web Viewer Blob](filemaker-web-viewer-series/README.md) develops a cumulative framework for modular FileMaker Web Viewers, explicit context, narrow action contracts, native-record ownership, and AI-assisted development.
- [FileMaker Toolbox](toolbox-series/README.md) collects focused interface techniques with small downloadable demonstration files.

Each article has its own folder. Start with that folder's README for the article, direct demo download, and supporting-material index.

## Downloads and Evidence

FileMaker `.fmp12` files are runnable demos. XML exports, tab-separated library exports, browser harnesses, and screenshots are supporting material; they are not substitutes for the native files. Screenshots identified as native evidence were captured from FileMaker. Browser previews and mockups are labeled separately.

## Compatibility

The Web Viewer demos were developed with FileMaker Pro 22. Compatibility for other releases is not yet claimed. Requirements and known limitations are documented with each demo.
