# Beyond the Web Viewer Blob

This series takes a FileMaker Web Viewer from a calculated HTML blob to a modular, inspectable interface. Each installment adds one capability while FileMaker remains the owner of records, selection, filters, authorization, and accepted application state.

## Articles

1. [Beyond the HTML Blob](articles/part-01-beyond-the-html-blob/README.md) separates the shell, platform modules, context bridge, page, and renderer.
2. [The Blob Talks Back](articles/part-02-the-blob-talks-back/README.md) adds a narrow JavaScript-to-FileMaker action path.
3. [Let the Record Show](articles/part-03-let-the-record-show/README.md) renders native FileMaker records and returns stable-id selection intent.
4. [The Prompt Thickens](articles/part-04-the-prompt-thickens/README.md) documents an AI-assisted hybrid-interface development and review loop.

The demos are cumulative teaching files. Later installments retain earlier platform capabilities, but each article keeps its own canonical prose, evidence, source exports, and downloadable `.fmp12` file.
