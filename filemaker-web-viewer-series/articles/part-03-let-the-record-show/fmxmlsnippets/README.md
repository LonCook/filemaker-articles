# Article 3 FileMaker Snippets

These article-specific snippets extend the cumulative demo for native ranked records:

- [`WV__Demo_Build_Context_Ranked.fmxmlsnippet.xml`](WV__Demo_Build_Context_Ranked.fmxmlsnippet.xml) builds ranked-view context from native FileMaker records.
- [`WV__Demo_Handle_Action_Ranked.fmxmlsnippet.xml`](WV__Demo_Handle_Action_Ranked.fmxmlsnippet.xml) validates stable-id selection and performs native navigation.
- [`WV__Demo_Run_All.fmxmlsnippet.xml`](WV__Demo_Run_All.fmxmlsnippet.xml) runs the ranked demo through the retained loading path.

They depend on the [shared framework snippets](../../../shared/fmxmlsnippets/README.md) and the schema documented in the [Article 3 source packet](../source/README.md). Paste only into a verified target FileMaker solution.
