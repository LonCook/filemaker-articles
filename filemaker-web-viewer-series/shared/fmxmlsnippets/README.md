- [`full_script_replacements_json_params/`](full_script_replacements_json_params/README.md) contains complete replacement scripts using JSON parameters.

The files use FileMaker `fmxmlsnippet` paste shapes. Verify the target script, required fields, helper scripts, and current solution conventions before pasting. XML snippets are installation aids, not proof that a native FileMaker change has been completed.
